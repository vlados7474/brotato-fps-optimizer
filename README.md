# Saffron Turbo — Endless FPS Optimizer & Lag Fix for Brotato

**Version:** `5.6.1` · **Game:** Brotato `1.2.0.3` · **Steam Workshop:** [Saffron Turbo on Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3845127629)

Smooth Endless waves without changing vanilla gameplay balance.

## Benchmark Highlight (Wave 200)
- **Vanilla:** `15 FPS` mean
- **Saffron Turbo 5.6.1:** `134 FPS` mean (**8.9×** faster)
- **Test system:** Intel Core i5-12400 · NVIDIA RTX 3070

## What's Inside
- `mod_main.gd` & `manifest.json` — ModLoader entry point and metadata
- `extensions/` — Godot 3.5.3 script extensions (entities, projectiles, floating text, particles, HUD, turrets)
- `scripts/` — Core optimization modules (damage canvas, spatial grid, interpolation, material pooling, targeting, governor)
- `presets/` — Ready-to-use profiles (`turbo_balanced.json`, `endless_max.json`, `vanilla_60hz.json`, `remote_play.json`)
- `docs/settings.md` — Configuration and preset reference

## Installation
1. Subscribe on [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3845127629) (recommended).
2. Or clone/download this repository for manual inspection — it contains **pure GDScript source code only** (no binaries, no vanilla game assets).
